    What the check looks for
    
    
    
      
    
        
    Data exposure
    
        
      
          
    • Tables with Row Level Security turned off
      • 
          
    • Policies that allow everything (using (true))
      • 
          
    • Views that ignore RLS or expose auth.users
      • 
          
    • Materialized views reachable through the API
      • 
          
    • Public storage buckets and open upload policies
      • 
        
    
      
    
      
    
        
    Privilege mistakes
    
        
      
          
    • Policies that trust user-editable user_metadata
      • 
          
    • SECURITY DEFINER functions callable through /rpc
      • 
          
    • Definer functions without a fixed search_path
      • 
          
    • Slow policies that call auth.uid() on every row
      • 
          
    • Extensions installed in an API schema
      •
